鳳凰颱風對蔬菜市場價量影響分析報告

專題紀錄與開發過程

  • 專題內容：本專題旨在分析 114 年 11 月（2025/11/01 - 2025/11/30）台灣各市場蔬菜交易行情，並重點探討 11/10 - 11/12 鳳凰颱風期間對市場價量的衝擊，藉此觀察不同蔬菜類別的抗災能力與市場預期心理。
  • 所使用的 AI：Gemini 3.1 Pro (Low) 作為開發助手，協助編寫爬蟲腳本、設計資料清洗與分析流程、以及自動化產出本視覺化報告。
  • 爬蟲設計與過程：針對農業部農產品批發市場交易行情站（AMIS），嘗試使用 httr 與 rvest 送出 POST 請求解析 HTML 表格。過程需處理 ASP.NET 特有的隱藏欄位（如 __VIEWSTATE）與表單驗證。
  • 遇到的困難：
    1. 目標網站原始下載按鈕會直接回傳二進位 Excel 檔案，但在 R 語言解析時遇到格式不符或底層函式庫（如 libxls）無法開啟的錯誤。最後透過解析回傳的 HTML Table 成功取得資料。
    2. 使用者環境中缺乏 Python 及 R Markdown 依賴的 pandoc 套件。為解決此問題，我們放棄使用 R Markdown 編譯，改以純 R 腳本（ggplot2）生成靜態圖檔，並將其透過字串拼接自動組合成此份 HTML 報告，達成完全無系統依賴的產出。
  • 爬取到的資料量：共成功爬取並清理出約 45,507 筆有效的蔬菜日交易紀錄。

以下為根據爬取資料所繪製的視覺化圖表與分析說明：

1. 整體蔬菜市場價量雙軸趨勢圖

颱風通常會在前夕引發預期心理的搶購潮（交易量上升），而在颱風過後因農損導致到貨量減少、價格上揚。下圖展示整體市場的日平均價格與總交易量走勢。

2. 颱風前後價格漲幅最大的 Top 10 蔬菜

我們比較了颱風前（11/01-11/09）與颱風後一週內（11/13-11/19）的產品均價，篩選出漲幅最劇烈的前 10 項蔬菜。

3. 不同「產品類別」的抗災能力分析

將蔬菜分為葉菜類、花果菜類、根莖菜類及菇類等，觀察不同類別在颱風來襲前後的價格波動幅度。葉菜類通常因不耐存放且易受水傷，價格波動最為劇烈。

結論總結

  1. 整體市場趨勢：在颱風期間（11/10-11/12），市場交易量出現震盪，而颱風過後隨著農損顯現與到貨量減少，整體平均批發價明顯上揚。
  2. 重災區品項：從漲幅 Top 10 來看，部分葉菜類及易受損的花果類價格飆漲最為顯著，顯示這些作物的抗災能力較弱或受損最為嚴重。
  3. 類別抗災差異：葉菜類的價格波動在颱風後呈現陡峭的上升曲線，而根莖類與菇類因生長環境或儲藏特性，價格走勢相對平穩。
