📊 台北二市場進口甜椒交易量短期波動分析

研究題目：進口蔬菜交易量的日間變化——以台北二市場甜椒為例（2026年4月）
使用 AI 工具：DeepSeek（深度求索公司開發的大型語言模型）
爬蟲技術：R 語言 + crul 套件，模擬 ASP.NET AJAX 請求
資料來源：農業部農產品交易行情網

1. 專題內容說明

本研究運用 R 語言爬蟲技術，從農業部農產品交易行情網站擷取台北二市場進口蔬菜的交易資料， 分析進口甜椒在 2026年4月18日至4月29日 期間的交易量波動。 因網站僅保留近一個月的交易紀錄，無法取得2月戰爭期間的歷史資料， 故將研究焦點調整為進口甜椒交易量的短期波動分析。

2. 爬蟲設計與過程

2.1 目標網站分析

  • 網站：amis.afa.gov.tw/veg/VegProdDayTransInfo.aspx
  • 架構：ASP.NET WebForm + AJAX UpdatePanel
  • 請求方式：POST，Content-Type 為 application/x-www-form-urlencoded; charset=UTF-8
  • 關鍵參數：__VIEWSTATE、__EVENTVALIDATION（每次請求需重新取得）
  • 日期格式：民國年（115/02/01），非西元年
  • 市場代碼：台北二 = 104

2.2 爬蟲流程

  1. 使用 crul::HttpClient 建立 HTTP 客戶端，自動管理 Cookie
  2. GET 初始頁面，以 rvest 解析三個隱藏欄位
  3. POST 查詢：市場=台北二(104)、日期=115/02/01~115/05/01、產品=7項進口蔬菜
  4. 解析 ASP.NET AJAX 回應格式（length|type|updatePanel|...|HTML）
  5. 從回應中擷取 HTML 表格並以 rvest::html_table() 解析
  6. 清理資料：移除導航文字、轉換民國年、數值型別轉換

2.3 遇到的困難與解決方法

困難原因解決方法
httr::POST 持續失敗ASP.NET ViewState 與 Session 綁定改用 crul 套件，自動管理 Cookie
Content-Type 錯誤使用 text/plain從瀏覽器 DevTools 確認為 application/x-www-form-urlencoded
日期格式錯誤使用西元年 2026/02/01改用民國年 115/02/01
市場名稱錯誤使用「台北二市場」應使用「台北二」
回應為 Error.htmViewState 過期每次 POST 前先 GET 取得新 ViewState
歷史資料無法取得網站僅保留近一個月資料調整研究題目為短期交易量分析

4. 視覺化圖表說明

圖 1：交易量長條圖

交易量在 4/25 和 4/26（週六、週日）達最高峰（350-400 公斤）， 而 4/19（週日）僅 100 公斤，為期間最低。波動幅度達 4 倍。

圖 2：交易量趨勢線（LOESS 平滑）

LOESS 曲線顯示交易量 先升後降，4/19 低谷後上升至 4/25-26 高峰，隨後回落。

圖 3：價格與交易量雙軸對照

價格（紅線）完全平穩（110 元/公斤），交易量（綠柱）則有明顯起伏。 這正是我們調整題目聚焦「交易量波動」的原因。

5. 分析結論

  1. 價格僵固性：進口甜椒價格完全穩定（110 元/公斤），可能因進口商有長期合約價格。
  2. 交易量波動：8 個交易日中交易量從 100 到 400 公斤，波動達 4 倍。
  3. 週末效應：週末交易量較高，可能因市場備貨需求增加。
  4. 研究限制：網站僅保留近一個月資料，無法取得 2 月戰爭期間數據進行前後對比。
  5. 爬蟲技術驗證：成功突破 ASP.NET WebForm + AJAX 防護機制。
