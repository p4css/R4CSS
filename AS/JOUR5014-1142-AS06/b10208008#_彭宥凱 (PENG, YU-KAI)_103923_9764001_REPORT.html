農產品市場價格分析報告

1. 專案內容

本專案旨在分析地理空間（產地 vs 消費地）對農產品價格的影響。透過抓取行政院農業委員會農產品批發市場交易行情站（AMIS）的歷史交易數據，我們比較了主要消費地「台北二」與南部產地「高雄市」在特定水果（芒果與西瓜）上的平均價格差異，藉此觀察運輸成本與市場供需對末端售價的影響。

2. 使用的 AI

本次專案全程由 Antigravity (Gemini 3.1 Pro) 協助開發，涵蓋專案初始化、網頁結構分析、爬蟲腳本撰寫、防錯機制設計，以及後續的資料清理與視覺化產出。

3. 爬蟲設計與過程

本專案使用 Playwright（非同步模式）搭配 Python 實作網頁自動化。為了精確模擬真人操作並應對 ASP.NET 動態網頁的特性，腳本中採用了以下設計：

  • 防崩潰機制：在每一個關鍵點擊與輸入動作後，嚴格加入 3 秒的等待延遲 (wait_for_timeout(3000))，確保伺服器回應與 DOM 渲染完成。
  • 動態選單處理：針對 ASP.NET 頁面透過 iframe 或彈窗動態生成的選項列表，採用了跨 frame 掃描與 JavaScript (evaluate) 文本比對的方式，精準選取了選項。

4. 遇到的困難與挑戰

環境安裝 (Python/Playwright)：初始執行環境中並未配置 Python，我們透過 winget 自動化指令為使用者安裝了 Python 3.11，並成功利用 pip 安裝相依套件與 Chromium 瀏覽器核心。

處理唯讀日期欄位：網站的日期輸入框設定為 readonly 並綁定了日曆彈窗的點擊事件。為了繞過繁瑣的日曆操作，我們直接利用 Playwright 的 evaluate 執行 JavaScript，強制將「過去一個月」的正確日期字串賦值給該輸入框。

ASP.NET 彈出視窗選項比對：由於產品選單的 value 與我們預想的代號可能存在差異（如附帶空白字元等），單純依靠原生的 select_option(value) 會遭遇超時找不到元素的錯誤。我們將邏輯改為利用 JavaScript 迭代所有的 <option>，透過 includes 模糊比對「芒果」、「西瓜」或代碼等關鍵字進行屬性勾選，成功解決了定位不到元素的問題。

5. 抓取資料量

本次爬蟲成功抓取了設定為過去一個月的歷史交易數據，針對指定的兩大市場與兩類水果，經過排除「小計」欄位與資料清理後，總計取得 12 筆 有效的逐項交易日均價紀錄。

6. 視覺化說明與結論
