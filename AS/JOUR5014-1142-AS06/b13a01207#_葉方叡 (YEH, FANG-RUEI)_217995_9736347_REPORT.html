農產品交易行情分析：水果的季節性觀察 (以台北二市場為例)

1. 專題內容與季節性定義

本專題旨在探討台灣常見水果的價格與交易量在「春夏秋冬」四季之中的變化。為了明確界定季節性，我們將月份劃分為： 春季 (3-5月)、 夏季 (6-8月)、 秋季 (9-11月)、 冬季 (12-2月)。

我們以台北二市場 (代碼：104) 為觀察對象，挑選了三種具代表性的水果：香蕉 (A1)、鳳梨 (B2) 以及 柳橙 (F1)，透過民國 113 年的全年交易資料，觀察它們在各個季節的盛產期與非盛產期表現。

2. 爬蟲設計與過程

我們初步嘗試利用 Selenium 自動化操作 AMIS 農產品交易行情網站，但發現該網站基於傳統的 ASP.NET 架構，大量依賴 ViewState 與 iframe，使得 UI 自動化操作不穩定。因此，我們改採官方提供的 農業部開放資料 API 發送 HTTP 請求，以確保穩定獲取所有季節的資料，並使用 Python 的 pandas 進行清理與季節分組標籤化。

(一) 水果交易量之季節性分佈 (盛產期觀察)

產季分析： 從上方的交易量趨勢可強烈看出水果的季節專屬性：
1. 冬季的王者 — 柳橙： 柳橙的交易量在 11 月進入秋末開始攀升，於 12 月、1 月 (冬季) 達到巔峰，隨後在春季迅速減少。
2. 春夏季的代表 — 鳳梨： 鳳梨在 4 月至 7 月期間交易量最大，是標準的春夏水果。
3. 全年皆有的常青樹 — 香蕉： 香蕉雖然一年四季皆有生產，但在不同季節的產量仍有微幅波動，並非絕對平穩。

(二) 水果價格與季節之反向關係 (價格趨勢)

價格波動分析： 結合上一張交易量圖表，我們能清楚觀察到「量多價跌，量少價揚」的市場法則：
1. 柳橙： 在冬季盛產時，平均價格落入最低點 (因供給量大增)；而在夏季幾乎無交易量時，市場上若有極少量釋出，價格往往偏高。
2. 鳳梨： 進入春夏盛產季時，隨著市場供給增加，價格曲線會出現明顯的下滑與回穩。
3. 香蕉： 夏季高溫時期可能因保存不易或風災影響，價格容易產生波動；而秋冬時期價格則相對平穩。

5. 產地與南北市場價格差異 (交通運輸影響)

水果的產地多集中於中南部（例如香蕉、鳳梨多產於屏東、高雄、台南一帶，柳橙多產於雲嘉南地區）。我們透過比較「台北二市場」與「高雄市市場」的年度平均交易價格，來觀察交通運輸與冷鏈物流對水果終端批發價格的影響。

南北市場水果平均價格比較

運輸成本分析： 從上圖可以明顯看出，同種類的水果在台北市場的平均批發價皆高於高雄市場。這段價差主要反映了：
1. 長途運輸成本： 從中南部產地運送至北部市場的油資與物流費用。
2. 損耗與保鮮： 運輸過程中的自然損耗，以及維持新鮮度所需的冷鏈或包裝成本。
3. 市場消費力與營運成本： 北部市場的土地租金、人工等營運成本較高，也會間接反映在拍賣與批發價格上。
