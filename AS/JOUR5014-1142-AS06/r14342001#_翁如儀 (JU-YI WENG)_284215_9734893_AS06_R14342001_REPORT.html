分析南北市場價差與交通運輸對特定水果價格的影響

新聞資料處理與視覺呈現專題報告 —— 以「愛文芒果」為例

一、專題內容與目標

本專題旨在探討台灣農產品在不同地理位置的批發市場中，其價格差異的形成原因。我們以夏季具代表性且易受運輸影響的「愛文芒果」為研究標的，透過收集歷史交易數據，分析其在「北部市場（如台北一、二）」與「中南部市場（如高雄、屏東）」的每日均價。

研究的核心假設在於：產地與消費地之間的距離所產生的交通運輸成本、以及運送過程中的耗損風險，是導致南北市場顯著價差的主要因素。透過數據佐證，我們期望能客觀呈現這項經濟現象。

二、爬蟲設計與過程

本專案的資料來源為農產品批發市場交易行情站 (AMIS)。由於該網站採用 ASP.NET 架構，含有大量的 __VIEWSTATE 與 __EVENTVALIDATION 等隱藏狀態參數，且多數查詢按鈕為 JavaScript 觸發的 PostBack 事件，單純使用 requests 模組難以模擬完整的交互過程。

  • 技術選擇：我們選用 Selenium 搭配 Chrome WebDriver 來進行瀏覽器自動化操作。
  • 操作流程：
    1. 自動開啟瀏覽器並進入 AMIS 首頁。
    2. 模擬使用者點擊左側導覽列的「產品日交易行情」。
    3. 在表單中輸入或選擇日期區間（例如芒果主要產季 5月至8月）。
    4. 輸入產品代碼「愛文芒果 (T1)」，並勾選目標市場。
    5. 點擊查詢後，利用 BeautifulSoup 或 Pandas 的 read_html 萃取回傳的表格資料。
  • 模組化：將爬蟲邏輯封裝於 scripts/scraper.py 中，並加入適當的延遲 (time.sleep 或 WebDriverWait) 以避免過度頻繁請求導致 IP 遭封鎖。

三、遇到的困難與解決方案

在資料蒐集與處理過程中，我們遭遇了以下挑戰：

  • 動態載入與表單驗證：
    困難：ASP.NET 的 WebForms 機制讓 URL 不會隨查詢改變，難以透過 URL 參數直接抓取資料。
    解決方案：引入 Selenium 自動化點擊與填表，讓瀏覽器引擎處理複雜的 JavaScript 與狀態保存，我們僅需攔截最終渲染出的 HTML。
  • 日期格式不一致：
    困難：政府開放網站常使用「民國年」格式（如 112/05/01），這會導致後續使用 Pandas 進行時間序列分析時發生解析錯誤。
    解決方案：在 scripts/process_data.py 中撰寫正規表達式與轉換函數，將民國年加上 1911 轉換為標準的西元年 (YYYY-MM-DD)。
  • 休市日與無交易紀錄處理：
    困難：市場並非每日皆有交易，導致時間序列出現斷層或產生 NaN 值。
    解決方案：利用 Pandas 的前向填充 (ffill) 或內插法 (interpolate) 補齊缺失值，並在圖表上標註休市狀態。
