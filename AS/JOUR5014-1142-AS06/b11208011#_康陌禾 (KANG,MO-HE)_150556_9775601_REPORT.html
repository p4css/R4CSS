台北一市場香蕉價格季節性分析

Assignment 6 ｜ 使用 AI 擷取與分析農產品交易行情資料

資料期間：2024-05-14 至 2026-05-14 ｜ 市場：台北一 ｜ 作物：香蕉

研究題目與目的

本專題以農業部農產品交易行情資料為來源，分析台北一市場香蕉在近兩年內的批發交易價格變化。 研究問題是：香蕉價格是否呈現明顯的時間變化或季節性？交易量與平均價格之間是否有可觀察的關係？

使用的 AI 與工具

  • Codex：協助解讀作業要求、建立專案規則、撰寫資料下載程式、檢查資料品質、產生圖表與撰寫報告。
  • Python：用於呼叫官方開放資料 API、整理 CSV、計算統計值與產生視覺化圖表。
  • Matplotlib：用於製作價格趨勢圖、每月平均價圖與價格交易量關係圖。

資料來源與取得方式

原始資料來自農業部農產品交易行情開放資料。資料集說明頁指出，資料包含交易日期、種類代碼、作物代號、 作物名稱、市場代號、市場名稱、上價、中價、下價、平均價與交易量等欄位。

資料集頁面： https://data.gov.tw/dataset/8066

本專題使用的 API： https://data.moa.gov.tw/Service/OpenData/FromM/FarmTransData.aspx

查詢條件設定為市場名稱 台北一、作物名稱 香蕉，日期範圍為 2024-05-14 至 2026-05-14。

爬蟲設計與處理流程

  1. 先檢查 AMIS 與政府開放資料平台，確認是否有官方 API 可用。
  2. 使用官方 API 取代直接解析網頁，降低網頁版面變動造成的錯誤。
  3. 透過 Python 程式分批下載資料，並設定市場、作物與日期條件。
  4. 只保留市場名稱為「台北一」且作物名稱精確為「香蕉」的資料。
  5. 將民國日期轉換為西元日期，並輸出成 CSV 檔。
  6. 再讀取 CSV 進行缺漏值檢查、基礎統計與視覺化。

遇到的困難

  • 一開始需要先確認 AMIS 網站是否必須使用網頁爬蟲，後來發現政府開放資料平台已有可用 API。
  • API 使用民國年格式，因此下載後需要轉換成西元日期，方便後續排序、統計與畫圖。
  • 作物名稱包含多種香蕉細項，例如「香蕉-其他」與「香蕉-芭蕉紅芭蕉」，因此本專題只保留作物名稱精確等於「香蕉」的資料，避免分析主題混雜。
  • 圖表輸出時中文字型可能因環境不同而顯示不穩定，因此圖表標題與座標採英文，中文說明放在報告文字中。

初步結論

從近兩年的資料來看，台北一市場香蕉的平均價格波動幅度相當大，最低平均價為 14.8 元/公斤， 最高平均價為 138.7 元/公斤，顯示香蕉批發價格可能受到季節、供給量、天候或市場需求影響。

每月平均價格圖顯示，不同月份之間的價格並不完全一致，適合進一步延伸分析季節性因素。 交易量與價格散點圖則可作為觀察供需關係的基礎；若要得到更嚴謹的結論，後續可以加入產地、颱風事件、 節慶需求或更多年份資料進行比較。
