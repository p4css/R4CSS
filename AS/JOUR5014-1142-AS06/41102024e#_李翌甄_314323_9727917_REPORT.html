專案成果報告

農產品交易行情爬蟲與資料視覺化分析

專題內容與主題設定

本專案的主題設定為：「水果的季節性：以台北二市場西瓜歷史價格與交易量為例」。

我們挑選了具有強烈季節性特徵的水果「西瓜（產品代碼：T1）」作為分析標的。透過爬取 2023 年全年度在「台北二（市場代碼：104）」市場的交易行情，旨在探討夏季盛產期時，西瓜的交易量變化以及對應的價格波動趨勢，驗證農產品「量多價跌、量少價揚」的市場供需法則。

所使用的 AI 工具

本次開發全程由 Google Antigravity 作為智能代理（Agentic AI），搭配強大的 Gemini 3.1 Pro 模型驅動。AI 負責了以下工作：

  • 規劃實作計畫（Implementation Plan）與任務追蹤（Task Tracking）。
  • 自動建立 Python 虛擬環境、安裝依賴套件（Playwright, Pandas, Matplotlib）。
  • 撰寫與除錯爬蟲腳本（Scraper）、資料清洗腳本，以及動態繪製視覺化圖表。
  • 嚴格遵守使用者指示，維護 LOG.md 工作日誌紀錄。

爬蟲設計與過程

資料來源為農委會的「農產品批發市場交易行情站（AMIS）」。該網頁是由 ASP.NET WebForms 開發的動態網頁，具有複雜的 ViewState 狀態與 AJAX 非同步加載特性。

  • 自動化工具選擇：捨棄傳統的 requests 靜態爬蟲，改採 Playwright 以無頭瀏覽器（Headless Browser）模式真實模擬使用者操作，確保能精準處理動態渲染的 HTML 與表單。
  • 操作流程自動化：透過腳本自動導航至「水果產品日交易行情」頁面，並設定日期範圍、市場代碼與產品代碼。
  • 資料提取：在查詢結果載入後，直接抓取網頁的完整 HTML 結構，再交由 Pandas 的 read_html() 進行表格解析。

遇到的困難與解決方式

在實作過程中，我們遇到了以下技術挑戰，並成功由 AI 代理自主排解：

  • 日期輸入框被鎖定 (Readonly)：
    網頁的日期輸入框設定為唯讀，必須透過點擊彈出日曆小工具才能修改。如果使用 Playwright 的 fill() 會引發逾時錯誤。
    解決方式：利用 Playwright 執行 JavaScript（page.evaluate），直接移除 readonly 屬性，隨後即可順利填入日期。
  • 複雜的下拉選單與 iFrame 彈窗：
    市場與產品的選擇並非單純的 <select>，而是觸發外部的 iFrame 選擇器，這使得自動化點擊極度耗時且容易不穩定。
    解決方式：分析網頁原始碼後，發現表單送出是依賴隱藏欄位（Hidden Fields）。因此直接使用 JavaScript 強制設定隱藏欄位 hfldMarketNo 與 hfldProductNo 的值，完美繞過複雜的 UI 互動，大幅提升爬蟲速度與穩定度。

視覺化圖表解析

為了清楚呈現價格與交易量的關聯，我們使用 Matplotlib 繪製了雙 Y 軸（Dual-axis）圖表：

  • 紅色折線：代表西瓜的「平均價（元/公斤）」。
  • 藍色長條圖：代表西瓜的「每日交易量（公斤）」。
2023年 台北二市場 西瓜 (T1) 價格與交易量趨勢圖

洞察分析：
從圖表中可以明顯觀察到，在 5 月至 8 月的夏季期間，藍色長條圖（交易量）呈現巨幅增長，符合西瓜盛產的季節特性。與此同時，紅色折線（平均價）在供貨量大增的期間並未出現劇烈崩跌，而是保持在穩定的區間內波動，這可能反映了炎熱天氣下，消費者對西瓜的需求量也同樣飆高，使得市場達成了高量高價或量價平穩的供需平衡狀態。
