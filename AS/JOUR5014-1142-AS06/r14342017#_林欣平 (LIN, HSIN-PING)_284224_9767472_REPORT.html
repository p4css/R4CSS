颱風過後，哪種菜最容易暴漲？

農產品交易行情資料爬取與視覺化分析專案報告

專題內容與目標

本專題旨在解答一個常見的民生問題：「颱風來襲前後，哪些蔬菜的價格波動最為劇烈？」。我們鎖定了農產品批發市場交易行情網 (AMIS)，針對特定颱風事件（如：2024年凱米颱風）前後的蔬菜批發價格進行數據爬取與分析，以數據佐證哪種蔬菜最容易成為「天價菜」。

使用的 AI 技術與輔助

Gemini 3.1 Pro Browser Subagent Image Generation

在專案過程中，我們利用了 AI 的多項能力：

  • 網站結構探勘：使用 `browser_subagent` 深入探索 AMIS 網站，確認其為使用 `__VIEWSTATE` 的動態 ASP.NET 網頁，從而決定採用 Playwright 進行爬蟲設計。
  • 腳本生成：由 AI 生成完整的 Playwright 爬蟲腳本 (`scraper.py`) 與資料模擬/分析腳本。
  • 視覺化生成：使用 `generate_image` 工具直接生成具有未來科技感與專業數據風格的高品質圖表。
  • 自動化專案管理：透過指令要求 AI 自動更新 `LOG.md` 以及建立 `CLAUDE.md` 規範。

爬蟲設計、過程與遇到的困難

爬蟲設計：目標網站 (https://amis.afa.gov.tw/main/Main.aspx) 是一個傳統的 ASP.NET 表單系統。我們採用 `Playwright` 以非同步方式操控無頭瀏覽器，自動填寫日期、開啟彈出視窗選擇市場（如：台北一）與作物代碼，最後點擊查詢並解析 `BeautifulSoup` 的 HTML 表格資料。

遇到的困難：

  • 網站採用大量的 JavaScript 彈出視窗（Modal）進行選擇，無法單純使用 GET/POST 傳遞參數。
  • 開發環境中遇到終端機權限問題 (`unexpected user interaction type: not permission`)，導致無法直接在系統中執行 Playwright 安裝與抓取指令。
  • 解決方案：AI 迅速切換策略，編寫完整的爬蟲邏輯代碼供未來運行，並使用 Python 腳本模擬了真實的颱風價格變動曲線以完成概念驗證與報告展示。
